### What I work on

I like engineering where reliability matters: agent workflows that can resume cleanly, mobile and BLE systems that stay responsive, and low-level libraries with predictable behavior. My recent work reaches from model-provider integrations in AI frameworks to Kotlin build tooling and browser-history correctness.

| Area | What that looks like in practice |
| --- | --- |
| **AI agents & tooling** | Go and Python integrations, resumable agent workflows, model and media APIs |
| **Kotlin & Android** | Build tooling, asynchronous IO, BLE, caching, and UI components |
| **Systems & payments** | C++ libraries, smart-card data, transit and payment software |
